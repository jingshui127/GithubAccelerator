# 安装与首次使用（一页看完）

本程序是一个**绿色工具**：解压即用，不写注册表、不装后台服务。

## 开始前（约 30 秒，可选但强烈建议）

1. 下载 `GithubAccelerator_v*_win-x64.zip`，解压到任意文件夹（建议英文路径）。**解压后请保持 exe 与旁边的 `Assets` 文件夹在一起**（托盘图标要用）。
2. 校验文件是否完整。打开 PowerShell，进入解压后的文件夹，执行：

```powershell
Get-FileHash .\GithubAccelerator.UI.exe -Algorithm SHA256
```

把输出与同目录 `SHA256SUMS` 里的那一行对比（只比哈希，不分大小写）。**对不上就别装**，删掉重新下载。

## 使用：两步

1. **双击 `GithubAccelerator.UI.exe`**。
2. 在首启页面点一次 **「🚀 开启网页加速」**。如果系统弹出"是否允许此应用更改…"，点「是」。

之后每次启动都是双击 → 界面会记住上次状态，直接可用。

## 首次运行会被拦：这是正常现象

本程序**没有购买代码签名证书**，所以 Windows SmartScreen 会显示"Windows 已保护你的电脑"：

1. 点提示框里的 **「更多信息」**；
2. 点 **「仍要运行」**。

部分杀毒软件也可能对未签名的新程序报"未知文件"。如果你不放心，可以先用上面的 SHA256 校验，再把文件提交给杀软厂商复查；本程序不联网下载额外组件，也不在后台驻留服务。

## 出问题了怎么办

- 主界面 → 帮助与支持 → **「🧾 生成问题报告（诊断包）」**：会先列出将要打包的文件与被脱敏的字段，确认后才生成本地 zip。**不会自动上传或发送**。
- 把 zip 发给我们即可定位问题；也可以先看 **帮助与支持 → 高级：日志**。
- 加速不生效时：先停止加速，再重新开始一次；仍不行就换一个数据源，或检查是否有其它软件改写了 Hosts。

本程序只修改 `C:\Windows\System32\drivers\etc\hosts` 中它自己的标记块，停止加速后只删除该块，块外内容保持原样。
